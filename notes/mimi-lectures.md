# 미미센세 「진짜 독학」 강의 노트 (교재: 가장 쉬운 독학 일본어 첫걸음)

재생목록: https://www.youtube.com/playlist?list=PLVpS91RyzrSU
강의는 교재 목차 순서를 따른다고 1강에서 직접 말함. 자동 자막(한국어)을 읽고 정리. 일본어 부분은 자막이 한글로 뭉개져서 내가 복원함.

## 1강 わたしは かんこくじんです (33:20) — v=NVO32BUF8RY → 교재 1과 はじめまして
- 인사: はじめまして / どうぞ よろしく おねがいします. どうぞ는 "부디", 장음이라 '도-조'로 두 박자. 원어민은 よろしく까지만 말하는 경우 많음, 정중할 땐 끝까지.
- 연말 인사 예: ことしも よろしく おねがいします(올해도 잘 부탁). おねがい(부탁) + します(합니다). 친구끼리 おねがい만.
- 1인칭: わたし(누구나, 가장 무난), ぼく(남자), あたし(여자). 교재는 ぼく도 씀.
- 조사 は는 '와'로 읽음.
- 반말: わたしは かんこくじん. 한국어 '-야'에 해당하는 말이 없음, 명사만 말하면 반말 완성. だ는 글말에 가깝고 친구끼리 잘 안 붙임(특히 여자).
- 존댓말: ~です ('데스'에 가깝게, 스 약하게). わたしは たなかです.
- か로 질문: にほんじんですか. 반말 질문은 억양만 올림(かいしゃいん↗).
- も = ~도: かれも にほんじんです. かれ는 '그 남자'(여자에겐 안 씀).
- あなた는 실제로 잘 안 씀. 그냥 にほんじんですか로 충분.
- これは なんですか / これ なんですか(は 생략 자연스러움).
- お 붙이면 정중: おしごと, おなまえ. 자기 것엔 안 붙임(ぼくの しごとは…).
- 부정: いいえ (반말은 ううん, 남자 いや). 반말 부정 じゃない, 존댓말 じゃないです / じゃありません / ではないです / ではありません 네 가지 다 OK. では의 は도 '와'.
- 발음: がくせい는 '각세-'에 가깝게(く 약하게). 작은 ゃ: かいしゃいん. ー는 길게: フリーランス.
- 실전 회화(교재 46쪽): 김시우와 다나카 유리에 첫 만남. 일본인은 친해지기 전엔 성+さん으로 부름.
- 단어: かんこく, にほん, かんこくじん, にほんじん, ちゅうごくじん, しごと/おしごと, なまえ/おなまえ, がくせい, かいしゃいん, これ, えんぴつ, エンジニア, せんせい, フリーランス, いしゃ.

## 2강 과거형 (36:26) — v=N6ND9VtVewk → 교재 2과 きのうは しゅっちょうでした (54~63쪽)
- 학습 내용: でした / じゃありませんでした / こそあど.
- やすみは いつですか(휴일은 언제예요). 반말은 いつ? / たんじょうび いつ? 만으로 자연스러움.
- まいしゅう どようびと にちようびですか. 毎 = まい(まいにち, まいしゅう). どようび는 '도요비'(장음 う는 거의 안 들림), 탁점 주의.
- 주: こんしゅう(이번 주) せんしゅう(지난주) せんせんしゅう(지지난주) らいしゅう(다음 주) さらいしゅう(다다음 주). 한자로 연상(先=선, 来=래).
- 요일: げつようび かようび すいようび もくようび きんようび どようび にちようび.
- 조사 と = ~와/~랑: ともだちと わたし, かんこくと にほん. 나라: アメリカ イギリス フランス ちゅうごく.
- 날: おととい きのう きょう あした あさって.
- 과거(반말·글말): 명사 + だった (せんせいだった, ともだちだった). 촉음 っ은 받침이 아니라 한 박자 쉬기.
- 과거(존댓말): 명사 + でした. "だったです"는 틀림(학생들이 많이 틀림).
- 질문: でしたか. 반말은 だった↗ 억양만.
- 반말 형태를 초반에 제대로 익혀야 나중에 문법 붙일 때 고생 안 함(이 책을 고른 이유).
- 과거 부정(반말): じゃなかった (がくせいじゃなかった, かれしじゃなかった, みずじゃなかった).
- 과거 부정(존댓말) 네 가지: じゃなかったです / じゃありませんでした / ではなかったです / ではありませんでした. 미미센세는 じゃなかったです를 제일 많이 씀.
- こそあど: これ それ あれ どれ / ここ そこ あそこ(예외) どこ / こちら そちら あちら どちら / この ひと, その ほん, あの つくえ, どの. "これひと"는 틀림. 일본인은 자기를 가리킬 때 코를 가리킴.
- 실전 회화(60쪽): しゅっちょうで やすみじゃありませんでした(で = ~라서), おつかれさまです, ホテルは どこでしたか, あの JKホテルでした.
- 단어: やすみ, いつ, たんじょうび, しゅっちょう, ともだち, かれし, みず, ひと, ほん, つくえ.

## 3강 な형용사 (33:42) — v=eCY1m_HLtes → 교재 3과 68·70·71쪽 + 5과 98·99쪽 + 6과 112·113쪽
- 주의: 형용사 파트는 책 순서를 안 따름. 책은 な/い형용사를 여러 과에 나눠 오가는데, 미미센세는 な형용사를 한 번에 다 정리하고 다음 강에서 い형용사를 정리함. 대부분 교재와 달리 な형용사를 먼저(명사와 문법이 100% 같아서 쉬움).
- 동사/형용사 구별 팁: "~하고 있다"를 붙여 자연스러우면 동사, 어색하면 형용사.
- な형용사 원형은 ~だ로 끝남: かんたんだ ゆうめいだ しんせんだ しずかだ すてきだ きれいだ はでだ しんせつだ にぎやかだ シンプルだ べんりだ.
- 활용은 명사와 똑같음: ゆうめい(반말) / ゆうめいじゃない / ゆうめいだった / ゆうめいじゃなかった / ゆうめいです / ゆうめいじゃないです / ゆうめいでした / ゆうめいじゃなかったです. 부정은 네 가지 다 가능, 하나만 골라 연습해도 됨. "しんせんだったです"는 틀림.
- 한국인이 특히 조심할 6개: すきだ きらいだ じょうずだ へただ とくいだ にがてだ. 모두 な형용사라 を가 아니라 が: にほんが すきです, えいごが じょうずです, えいごが へたです, むしが きらい, うたが へた, あなたが すき.
- 명사 수식은 な: かんたんな もんだい, ゆうめいな ひと, きれいな スカート, しんせつな ともだち, シンプルな デザイン. (그래서 이름이 な형용사)
- 부사는 に: かんたんに, しずかに, シンプルに, きれいに, しんせつに.
- 연결은 で: しんせつで きれいです, きれいで ゆうめいです, この スマホは デザインが シンプルで べんりです. 핸드폰은 요즘 スマホ.
- 예문: わたしの せんせいは しんせつです, これは しんせんじゃないです, ここは にぎやかでした, その もんだいは かんたんじゃなかったです.

## 4강 い형용사 (34:58) — v=_BJd8GWGs2s → 교재 3~6과의 い형용사 부분 (쪽수 언급 없음)
- い형용사는 원형이 い로 끝남: あつい さむい ながい かわいい やすい おもしろい おいしい たかい いそがしい からい はやい ほしい.
- 원형 = 반말(사전형). かわいい는 い 두 개, '가와이-'로 길게.
- 부정: い 빼고 くない (あつくない, かわいくない, やすくない, おもしろくない). 'あついくない' 틀림.
- 과거: い 빼고 かった (あつかった, かわいかった, おいしかった, おもしろかった).
- 과거 부정: くない → くなかった (あつくなかった, たかくなかった, いそがしくなかった).
- いい는 활용 불가, よい로: よくない, よかった, よくなかった. よかった는 "다행이다"로도 씀.
- 존댓말은 뒤에 です만: あついです, あつくないです, あつかったです, あつくなかったです. 부정 존댓말 대안: くありません / くありませんでした (둘 중 하나만 골라 연습해도 됨).
- 명사 수식은 그대로: かわいい スカート, たかい ふく, あつい くに. ~ですね(감탄): かわいい スカートですね.
- 부사는 く: やすく して ください(싸게 해 주세요), はやく して ください, おいしく, からく して ください. すみません을 すいません이라고도 함.
- 연결은 くて: やすくて いいです, かるくて いいですね(モバイルバッテリー), かわいくて きれいです.
- ほしい도 い형용사라 が: なにが ほしい?, おかねが ほしい. を는 틀림.
- 단어: たんじょうび プレゼント, くに, ふく, スカート, モバイルバッテリー.

## 6강 ね・よ + 3~6과 본문 (26:51) — v=p8NI1WU4xfw → 교재 3·4·5·6과 본문(회화)

- かえます(살 수 있다)는 가능형, 지금은 통째로 외우기.

## 7강 동사 그룹 (20:50) — v=kyqx_E2Rh8o → 교재 152쪽 (동사 그룹 설명, 9과 부근)

- 10과 본문: かいしゃは なにで いきますか(なにで = 무엇으로; なんで로 읽으면 '왜'가 되니 주의) / バスで いきます / ケーキは なにで たべますか / フォークで, はしで / かいしゃまでは どのぐらい かかりますか / いちじかんぐらい かかります / しごとの あとで すぐ うちへ かえりますか(명사+명사는 の: じゅぎょうの あと, うんどうの あと) / いいえ、すぐ かえりません. ジムに いきます / たまに ともだちに あいます.

## 10강 ある vs いる (31:56) — v=rfKibFFFYV8 → 교재 7과(124~127쪽), 8과(138~140쪽)
- 책은 동사보다 먼저 ある/いる를 배우지만, 둘 다 동사라 미미센세는 ます형 다음으로 순서를 바꿈.
- ある: 스스로 자리를 옮길 수 없는 것(사물·식물·장소, 시간·꿈 같은 추상). いる: 스스로 이동할 수 있는 것(사람·동물). 기준은 '흔들림'이 아니라 '이동'.
- 예: コーヒーと おちゃが ある, タブレットが ある, ゆめが ある / わたしは いま へやに いる, きょうだいが いる, いえに いぬと ねこが いる.
- ある는 1그룹 → あります, いる는 2그룹 → います. 부정 ありません, いません. 반말 '있어'는 그냥 ある/いる.
- 예: ルームには なにが ありますか, つくえの うえに わたしの ほんが あります(명사+명사는 の), その まえに びょういんが あります, かばんの なかに さいふが あります, どこに いますか, がっこうに います, ゆうびんきょくに います.
- 위치어: うえ まえ なか (교재엔 した うしろ となり 등도 있을 것).
- お는 말을 곱게 하는 미화어, 없어도 됨: おみず/みず, おさけ, おかね. コーヒーは ありません, おみずは ありません, おさけは ありません.
- いません 예: きょうだいは いません. ひとりっこです / がくせいが だれも いません(だれも = 아무도) / いえに ペットは いません.
- 없다(반말): ない(물건) / いない(사람·동물). い형용사라서 존댓말은 です: ないです, いないです.
- 결론: 없어요는 ありません = ないです, いません = いないです 둘 다 OK.
- 예: ここは はなが ない, コンビニが ない, いま じかんが ない / ここは ひとが まったく いない, がくせいが いない, いえに ペットは いない. おかねが ある/ない/あります/ありません/ないです, ともだちが いる/いない/います/いません/いないです.
- 머리로 알아도 말할 때 자꾸 틀리니 입에 붙을 때까지 소리 내서 반복하라고 강조.

## 11강 7·8과 본문 + 가족 호칭 (23:52) — v=LQDqLe0sOmQ → 교재 7과 본문(130쪽), 8과 본문(144쪽), 가족 호칭(139쪽)
- 7과 본문(호텔): ルームには なにが ありますか / せっけんや はブラシや はみがきこなどが あります(や…など = ~나 ~ 등, 대표 몇 개만 말할 때) / おみずは テーブルの うえに あります / コーヒーも ありますか / いいえ、コーヒーは ありません / れいぞうこの なかに なにか ありますか / いいえ、なにも ありません.
- なにが(뭐가 있는지 묻기) vs なにか(뭐라도 있는지 묻기) 발음·뜻 다름. だれが vs だれか도 같음. なにも/だれも + 부정 = 아무것도/아무도.
- 발음: コーヒー는 ひ를 또렷하게 + 장음. はみがきこ는 き를 약하게.
- や 예: きゅうりや たまねぎなどを かいました.
- 8과 본문(가족): へやの なかに だれか いますか / ちちと おとうとが います / おかあさんも いますか / いいえ、はは은 いません. ははは そとに います / トイレに だれか いますか / いいえ、だれも いません(だれも ありません은 틀림).
- 가족 호칭: 교재는 "내 가족 = はは·ちち, 남의 가족 = おかあさん·おとうさん"이라고 하지만 실제로는 はは·ちち·そふ·そぼ·あに·あね는 '겸손 떨 때(낮출 때)' 쓰는 말. 엄마를 직접 부를 때나 친한 친구한테 우리 엄마 얘기할 땐 おかあさん(うちの おかあさんが…). 한국어 '저희 엄마'를 쓸 상황이면 はは.
- 부를 때: おとうさん おかあさん おにいさん おねえさん おじいさん おばあさん. おとうと·いもうと는 아랫사람이라 さん 붙이면 진짜 남의 동생.
- 예: この ひとが シウさんの おとうさんですか / はい、ちちの しゃしんです.
- 다음 강: て형(교재 208쪽).

## 12강 て형 (22:17) — v=VdfjRWUdizM → 교재 13과 부근(208쪽 て형, 211쪽 てください)
- て형의 대표 역할은 연결(~하고/~해서). ごはんを たべて コーヒーを のみます, えいがを みて…, おきて コーヒーを のみます.
- 2그룹: る → て (たべて みて おきて あけて).
- 3그룹: する → して, くる → きて. べんきょうして, ともだちは まいにち がっこうに きて コーヒーを のみます.
- 1그룹(반짝반짝 작은 별 멜로디): う·つ·る → って(かって まって うって) / む·ぶ·ぬ → んで(のんで あそんで しんで) / く → いて(きいて かいて) / ぐ → いで(およいで いそいで) / す → して(おして はなして).
- ~て ください = ~해 주세요. まって ください, はやく のんで ください, わたしと あそんで ください, よく きいて ください, はやく かいて ください, いっしょに およいで ください, いそいで ください, おして ください(자동문 버튼에 써 있음), かんこくごで はなして ください. わたしに うって ください.
- ください를 빼면 반말 명령·부탁: まって(기다려), いそいで, それ わたしに うって.
- コーヒーを かって のみました.
- 강의 자막에는 いく → いって 예외 언급이 없음(교재에는 있을 것, 내가 덧붙이는 사실).

## 요약: 강의 ↔ 교재 ↔ 앱
- 강의는 1·2강까지 교재 1·2과와 1:1, 3강부터는 미미센세 순서로 재편집(형용사 몰아서, 숫자 몰아서, 동사 먼저, 본문 몰아 읽기).
- 1강=1과, 2강=2과, 3강=な형용사(3·5·6과), 4강=い형용사(3~6과), 5강=숫자(4·5·10과), 6강=3~6과 본문+ね·よ, 7강=동사 그룹(152쪽), 8강=ます형(153·167·194·196쪽), 9강=9·10·12과 본문, 10강=ある/いる(7·8과), 11강=7·8과 본문+가족 호칭, 12강=て형(208·211쪽).
- 아직 강의가 없는 부분: 11과 일부, 13과 이후(て형 다음 단원들). 재생목록은 계속 올라오는 중(12강이 3주 전).
