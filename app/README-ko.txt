일본어 6주 앱 설치 방법
=======================

이 폴더가 앱 전체야. 인터넷 주소에 한 번 올린 다음, 폰에서 그 주소를 열어 홈 화면에 설치하면 된다.
설치한 뒤에는 인터넷이 없어도 돌아가.


1. 인터넷에 올리기 (한 번만, PC 추천)
------------------------------------
가장 쉬운 방법: Netlify

  1) netlify.com 에 가입한다. 구글 계정으로 가입해도 된다.
  2) 로그인한 상태로 app.netlify.com/drop 을 연다.
  3) 압축을 푼 nihongo6-app 폴더를 통째로 화면에 끌어다 놓는다.
  4) 몇 초 뒤에 xxx.netlify.app 같은 주소가 생긴다. 이게 내 앱 주소다.

  주의: 로그인하지 않고 올리면 한 시간 안에 지워진다. 꼭 로그인한 다음에 올려.
  주소 이름은 Site configuration > Change site name 에서 바꿀 수 있다 (예: nihongo6-me.netlify.app).

다른 방법: GitHub Pages
  새 저장소를 만들고 폴더 안의 파일을 전부 올린 다음, Settings > Pages 에서 main 브랜치를 켜면 된다.


2. 폰에 설치하기
----------------
아이폰
  1) Safari 로 앱 주소를 연다. (크롬 말고 Safari)
  2) 아래쪽 공유 버튼 > "홈 화면에 추가" > 추가.
  3) 이제부터는 꼭 홈 화면의 빨간 あ 아이콘으로 연다.
     Safari 에서 연 기록과 아이콘으로 연 기록은 따로 저장된다.

안드로이드
  1) 크롬으로 앱 주소를 연다.
  2) 화면에 "설치하기" 버튼이 뜨면 누른다. 안 뜨면 메뉴(⋮) > "앱 설치" 또는 "홈 화면에 추가".


3. 세트 알림 넣기
-----------------
앱 안의 "나" 탭 > "폰 캘린더에 세트 알림 넣기" 를 누르면 캘린더 파일이 받아진다.
파일을 열고 "모두 추가"를 누르면 11/25 ~ 1/6 의 세트 129개가 알림과 함께 캘린더에 들어간다.
세트 시간을 바꿨으면 파일을 다시 받아. 예전 일정은 캘린더에서 지우면 된다.
기본 시간(10:00 / 16:00 / 22:30) 파일은 이 폴더의 calendar.ics 에도 들어 있다.


4. 기록 저장
------------
공부 기록과 카드는 폰 안에만 저장된다.
일주일에 한 번 "나" 탭 > "백업 파일로 저장" 을 해 두면 폰을 바꿔도 "백업 붙여넣어 복원"으로 이어서 할 수 있다.


5. 앱 고치기 / 업데이트
-----------------------
새 버전 폴더를 받으면 Netlify 사이트의 Deploys 화면에 다시 끌어다 놓으면 된다.
폰에서는 앱을 한 번 껐다 켜면 새 버전이 적용된다. 기록은 그대로 남는다.


6. Claude 안에서만 되는 기능
----------------------------
AI 하루토 자유 대화, "이 말 일본어로?" 번역은 Claude 안에서 열 때만 켜진다.
설치한 앱에서는 이 두 개만 안 보이고 나머지는 전부 똑같이 된다.
